Описание: 
Веб-сервер для составления и планирования задач с правилами их повторения. Задачи хранятся в БД SQLite, реализовано API для удаления, добавления, редактирования, а так же отмечать задачи как выполненные.

Запустить локально:
1. go mod tidy // установка зависимостей
2. Задать переменные окружения:
set TODO_PORT=7540
set TODO_DBFILE=scheduler.db
set TODO_PASSWORD=12345
3. Запустить сервер:
go run main.go

После откройте окно в браузере и перейдите по адресу  http://localhost:7540/

Для прогонки тестов необходимо перед их запуском выставить корректные параметры в файле tests/settings.go:
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true // реальзованы правила w и m
var Search = true       // реализован поиск
var Token = ""          // токен из /api/signin
После настройки откройте отдельный терминал и запустите сервер с последующими тестами:
go run main.go
go test ./tests
